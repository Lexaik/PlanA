Проект веб-приложения "PlanA" для планирования производства изделий, выполнения заказов и поставок материалов для малых и средних предприятий.
На основе усреднённых данных происходит определение длительности выполнения работ.
При расчёте даты выполнения заказа учитывается наличие материала на складе или срок его поставки, количество работников на расчётный период (отпуск, обучение и т.п.), сотояние и количество оборудования (ремонт, обслуживание и т.п.).
Так же дата выполнения заказа рассчитывается с учётом текущей загруженности производства (текущие заказы).
